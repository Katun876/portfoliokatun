# Портфолио — Екатерина, UX/UI-дизайнер

Адаптивный одностраничный сайт по макетам Figma (Page 13: `D` — 1440 px, `M` — 390 px).

- Чистые HTML / CSS / JS, без сборки и зависимостей — открывается как статический сайт (GitHub Pages).
- Шрифты Inter и IBM Plex Mono подключены локально (`assets/fonts`).
- 13 проектов + карточка «Больше работ» в горизонтальной ленте: стрелки, свайп, drag мышью, клавиши ←/→, счётчик и прогресс.
- Фильтры «Мобильные / Веб / Лендинги / Системы», просмотр карточки в лайтбоксе с кнопкой «Запросить кейс».
- Мобильное меню, липкая навигация с подсветкой текущего раздела, мягкое появление блоков, `prefers-reduced-motion`.
- Изображения в WebP (весь сайт ≈ 2 МБ).

## Публикация на GitHub Pages
Settings → Pages → Source: *Deploy from a branch* → `main` / root.

## Как обновить карточку проекта
Экспортируйте карточку 440×640 из Figma в 2× (880×1280), сохраните в `assets/works/<имя>.webp` и поправьте подпись в `index.html`.
